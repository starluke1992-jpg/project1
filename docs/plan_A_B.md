# 方案 A / 方案 B：原则与实现路径

这份文档来自对"避险猫"27 篇文章的分析。文章里站得住的骨架保留下来：风险平价、目标波动率、趋势过滤、趋势跟踪，全部改用公开、简单的方法实现。文章暴露的问题，比如反复调参、事后挑资产、数据处理不当、人工干预，在这里预先写成规则。

**目标是复制方法，不是复制文章里的回测数字。**

## 0. 两个方案一览

| | 方案 A：ETF 趋势过滤风险平价 | 方案 B：期货组合 |
|---|---|---|
| 子策略 | 一个 | B1 杠杆风险平价、B2 趋势跟踪 CTA，两者分账运作 |
| 收益来源 | 各类资产的风险溢价；趋势过滤躲开深跌 | B1 同 A，另加杠杆；B2 赚趋势收益（危机 alpha） |
| 杠杆 | 无 | B1 ≤ 2.5 倍，B2 ≤ 3 倍（按名义金额） |
| 调仓频率 | 每月 | 每周 |
| 资金门槛（估计） | 几万元 | B2 约 100 万元起；B1 纯用期货需要数百万，资金不够用混合方案 |
| 合理预期（个人判断，不是计算结果） | 年化 4–7%，最大回撤 8–15% | B1 年化 6–10%；B2 夏普 0.4–0.8，会有一两年不赚钱 |
| 建议顺序 | 先做 | A 跑通之后再做 |

## 1. 总原则

### 1.1 投资原则

1. **分清收益从哪来。** A 和 B1 赚的是风险溢价（beta），B2 赚的是趋势收益。不把 beta 叫作 alpha，也不拿一个策略的业绩去证明另一个。
2. **按风险分配仓位，不按资金分配。** 权重由波动率决定。组合的总风险用波动率目标（或上限）和杠杆上限来管。
3. **资产按经济角色事先选定。** 选每个资产时问的是"它在组合里起什么作用"，不是"它过去涨得好不好"。纳指、30 年国债这类事后看表现最好、角色又和已有资产重复的，不放进来。CTA 的品种池由流动性规则逐日生成，不手工挑。
4. **简单优先。** 每个模块先用最简单的公开方法。复杂方法要在开发期样本里稳定胜出才能替换：夏普至少高 0.1，并且通过参数敏感性测试。
5. **接受不赚钱的年份。** 不把"每年正收益"当目标，这个目标会直接诱导过拟合。能接受多大的回撤、多长的平台期，事先写下来。
6. **预期打对折。** 样本外的夏普按回测的一半来估。

### 1.2 研究原则（防止过拟合）

1. **样本切分固定不变。** 开发期是 2011–2018 年，留出期是 2019 年至今。所有设计和调参只用开发期；规则冻结后，留出期只跑一次。
   - 留出期正好赶上中债和黄金的大牛市，对这类策略偏有利，所以留出期的结果也要打折看。
2. **登记每一次试验。** 每次回测（包括失败的）都写进 `research/trials.csv`：日期、改了什么、结果如何。最终版本要报告总共试了多少次，并计算缩减夏普比率（Deflated Sharpe Ratio，Bailey & López de Prado 2014）。
3. **参数选平稳区的中间，不选最高点。** 主要参数在测试范围内变动时，结果应该基本平稳。取这片平稳区的中央，不取结果最好的那一格。
4. **计算口径统一。**
   - 收益用日度简单收益。夏普 = (年化收益 − 现金收益) / 年化波动，现金收益取 7 天回购利率或货币基金收益。
   - 相关性一律用收益率计算，不用价格水平。
   - 代理数据（用指数代替期货或 ETF）一律换算成可交易的口径：指数收益要扣掉 ETF 费率；加了杠杆的部分要扣融资成本，也就是用超额收益。
   - 境外资产统一换算成人民币计价。
5. **不用未来数据。**
   - 信号在 T 日收盘时确定，T+1 日成交。
   - 所有信号都要通过截断测试：删掉 T 日以后的数据，T 日及之前的信号不变。仓库现有测试已经有这个写法。
   - 换月目标合约和品种池筛选，也只能用 T 日及以前的数据。
6. **先跑基准。** 每个策略都要和更简单的版本比较：A 比静态风险平价、等权、股六债四（60/40）；B2 比朴素的 12 个月动量。赢不了简单版本，就直接用简单版本。

### 1.3 风控原则

1. 组合层面设五道限制：波动率目标或上限、名义杠杆上限、单个资产上限、单个板块的风险上限、保证金占用上限。
2. 波动率估计设下限，防止某个资产在低波动时期权重暴涨。
3. 失效和停止条件事先写好（见第 6 节）。回撤期间不临时改规则。

### 1.4 执行原则

1. 先跑 3–6 个月模拟盘，再用小资金实盘，之后逐步加资金。
2. 实盘不做人工干预。例外只有三种：数据错误、交易所规则变化、流动性异常。每次例外都要登记原因。
3. 子策略分账运作，至少分开记持仓，不合并信号。作者 2026 年 1 月就在这里吃过亏。
4. 每月比较实盘和模型的偏差。偏差大时，先查执行和数据，不先改模型。

## 2. 方案 A：ETF 趋势过滤风险平价

### 2.1 资产池

|---|---|---|---|
| 权益 | 沪深 300 | 510300 | 沪深 300 全收益指数（H00300） |
| 权益 | 中证 500 | 510500 | 中证 500 全收益指数（H00905） |
| 权益 | 红利低波 | 512890 | 红利低波指数，优先用全收益版本 |
| 权益 | 恒生指数 | 159920 | 恒生指数总回报，换算成人民币 |
| 权益 | 标普 500 | 513500 | 标普 500 总回报，换算成人民币 |
| 债券 | 10 年国债 | 511260 | 10 年期国债指数（财富或全收益口径） |
| 黄金 | 黄金 | 518880 | 上海黄金交易所 Au99.99 |
| 商品 | 豆粕 | 159985 | 豆粕期货复权连续 |
| 商品 | 有色 | 159980 | 有色期货复权连续 |
| 商品 | 能化 | 159981 | 能化期货复权连续 |
| 现金 | 货币基金 | 511880 | 7 天回购利率累计 |

说明：
- **没放纳指、中证 1000、30 年国债。** 纳指、中证 1000 和已有资产的角色重复；30 年国债和 10 年国债是同一个利率因子，只是放大了。三者又都是事后看表现最好的选择。
- **商品 ETF 2019 年底前后才上市。** 上市之前的历史用期货复权连续补齐，并扣除 ETF 费率。
- **用指数补齐 ETF 历史时，每年扣掉 ETF 费率。** 境内 ETF 大约 0.2–0.6%，QDII 大约 0.6–0.8%。

### 2.2 规则（v1；冻结前只允许在开发期内调整）

| 步骤 | 规则 |
|---|---|
| R1 波动率 | 每个资产的 σ = 过去 60 日日收益的标准差 × √252，下限 2% |
| R2 大类内的权重 | 按波动率倒数分配：w ∝ 1/σ |
| R3 大类之间的权重 | 权益、债券、黄金、商品四类，风险预算各占 25%。先算每类子组合过去 60 日的波动 σ_c，类权重 ∝ 25% / σ_c，四类合计 100% |
| R4 趋势过滤 | 每个资产算一个暴露系数 e = 0.5 ×［收盘价 > 200 日均线］+ 0.5 ×［过去 252 日收益 > 同期现金收益］，e 只能是 0、0.5 或 1。资产权重乘以 e，减下来的部分转成现金，不分给其他资产 |
| R5 波动率上限 | 用过去 120 日收益（做 Ledoit-Wolf 收缩）估计组合波动 σ_p。σ_p 超过 6% 时，所有风险资产按同一比例缩小到 6%，差额转现金。只缩小，不放大 |
| R6 单个资产上限 | 单个资产不超过 50%（实际只会限制到债券），超出部分转现金 |
| R7 调仓 | 每月最后一个交易日收盘后计算，下一个交易日执行。某个资产要调整的幅度不到净值的 1% 时，不调 |
| R8 成本 | 佣金单边万分之 1.5。滑点：宽基、黄金、国债 ETF 按 2 个基点，商品 ETF 和 QDII 按 5 个基点 |
| R9 QDII 溢价 | 实盘规则：溢价超过 3% 时，暂停买入这只 ETF。回测里模拟不了，要在报告中注明 |

为什么这样设计：
- **分两层做风险预算**，是为了避免权益资产只因为数量多就拿到更大权重。
- **趋势过滤用两个信号各占一半**，可以减少对单个参数的依赖，也减少来回翻转。
- **波动率只设上限、不放大**，因为方案 A 不加杠杆。往上放大只会把风险集中到剩下的少数几个资产上。

### 2.3 参数测试范围（事先写定）

| 参数 | v1 取值 | 测试范围 |
|---|---|---|
| 波动率窗口 | 60 日 | 20 / 40 / 120 日 |
| 均线 | 200 日 | 150 / 250 日 |
| 动量回看期 | 252 日 | 126 / 189 日 |
| 波动率上限 | 6% | 5% / 8% |
| 调仓频率 | 每月 | 每两周 |
| 大类风险预算 | 四类各 25% | 权益 30 / 债券 30 / 黄金 20 / 商品 20 |

### 2.4 验收标准（冻结前写定，不为了通过而调参）

1. 留出期夏普 ≥ 0.5；全样本最大回撤 ≤ 15%。
2. 和"静态两层风险平价"（即不加趋势过滤的版本）比，最大回撤更小，夏普不低于它减 0.1。做不到，说明趋势过滤不值得加，改用静态版本。
3. 第 2.3 节测试范围内的所有参数组合，夏普的最高值和最低值相差不超过 0.3。
4. 每次去掉一个资产重跑，夏普下降不超过 30%。重点看去掉黄金和去掉债券的结果。
5. 成本翻倍、成交再推迟 1 天，夏普下降都不超过 0.15。
6. 截断测试通过。报告里列出事前设定的波动率和事后实际的波动率。

## 3. 方案 B：期货组合（B1 + B2）

### 3.1 结构

- **B1 和 B2 分账运作**，至少要分开记持仓，各自算信号、各自算盈亏，不合并信号。同一个合约下单时可以轧差，省一点成本，但盈亏要分开记。
- **资金按 B1 : B2 = 60 : 40 分配**，每半年再平衡一次。
- **另外预先登记一个对照版本：B1 不加趋势过滤。** 理由是 B2 已经提供了趋势收益，B1 再过滤可能是重复的。

### 3.2 共用的基础设施

1. **合约规格表** `config/futures_specs.csv`：品种、交易所、合约乘数、最小变动价位、保证金率（交易所的加上期货公司加收的）、手续费、上市日期、有没有夜盘、对个人持仓的限制。
2. **逐合约的日线数据**：每个合约的开高低收、成交量、持仓量。
3. **换月规则：**
   - 个人账户一般不能把仓位带进交割月，所以统一在"交割月的前一个月的月中"之前，换到下一个主力合约。具体日期以各交易所规定为准。
   - 换到哪个合约，只能根据 T 日及以前的成交量和持仓量来定。
4. **两套价格：** 算信号用按比例复权的连续价格；算盈亏用实际合约的价格，换月记两笔交易成本。
5. **回测引擎要处理的事：**
   - 每日按收盘价结算盈亏
   - 只能买卖整数手
   - 保证金占用不超过权益的 40%
   - 手续费，加上每边 1 跳的滑点
   - 涨跌停封板当天成交不了，顺延到下一天
   - 没占用的资金按货币基金收益计息
6. **最小可行资金报告：** 给定一笔资金，算出按整数手取整之后的实际组合和理想组合差多少（跟踪误差），找出差距可以接受的最小资金。

### 3.3 B1：杠杆风险平价

| 项目 | 规则 |
|---|---|
| 品种 | 权益：IF、IC；利率：T（10 年国债期货）；黄金：AU；商品：CU、AL、RB、I、M、Y、TA、MA、SC。每个品种上市满 250 个交易日后才纳入 |
| 权重 | 和方案 A 的 R1–R4 相同：分两层做风险预算，再做趋势过滤 |
| 风险目标 | 组合目标波动 8%，可以放大也可以缩小。名义杠杆不超过 2.5 倍，保证金占用不超过 40% |
| 调仓 | 每周计算。实际仓位和目标相差至少 1 手、且至少相差 10% 时才调 |
| 历史补齐 | T 合约 2015 年 3 月才上市，之前用"10 年国债指数收益减 7 天回购利率"的超额收益代替。SC 2018 年才上市，之前不纳入，也不拿燃油代替 |
| 压力测试 | 2013 年钱荒（用代理数据）、2015 年股灾、2016 年底债市大跌、2020 年 3 月、2022 年商品急涨 |

**资金问题：** IF、AU、T 一手的面值都接近或超过 100 万元。纯用期货做 B1，要有数百万资金才能按风险配准。资金不够时用**混合方案**：股票和黄金用 ETF，只用国债期货给债券加杠杆。

### 3.4 B2：趋势跟踪 CTA

| 项目 | 规则 |
|---|---|
| 品种池 | 每个调仓日按规则生成，不手工挑：上市满 250 个交易日；过去 60 日主力合约日均成交额 ≥ 5 亿元；一手保证金不超过账户资金的 5% |
| 板块 | 股指、利率、贵金属、有色、黑色、能化、农产品；每个板块的风险不超过 25% |
| 信号 v1 | 分别看过去 20、60、120、250 日的涨跌方向（用复权价格），涨记 +1、跌记 −1，四个取平均，所以信号 s 只能是 −1、−0.5、0、0.5、1 |
| 仓位 | 原始权重 = s / σ（σ 用 60 日波动）。用带方向的持仓算协方差（做 Ledoit-Wolf 收缩），把整个组合缩放到年化波动 10%。名义杠杆不超过 3 倍，单个品种的风险不超过 10% |
| 调仓 | 周五收盘算信号，下周一执行。仓位相差至少 1 手、且至少相差 10% 时才调 |
| 出场 | v1 只按信号变化出场，不另设止损 |
| 成本 | 交易所手续费 × 1.3（近似期货公司加收的部分），每边 1 跳滑点，换月记两笔交易 |

**对照组**（预先登记，用同一套组合构建方法）：
1. 朴素的 12 个月动量：s = 过去 250 日收益的正负号。
2. 仓库现有的 `trend_signals`（BOLL + KAMA + 波动率角度），把它输出的 position 当作 s。它原来按当根 K 线收盘价成交，接进来时要改成 T+1 成交。
3. v1 再加上仓库里已有的 ATR 吊灯止损。

如果 v1 在开发期的夏普比朴素 12 个月动量高不出 0.1，就用朴素版本。

**资金：**
- 中小合约（豆粕、螺纹、甲醇、玻璃等）一手面值几万元。
- 铜、黄金、原油、股指、国债一手面值几十万到上百万元。
- 粗略估计，约 100 万元能覆盖二十个左右的中小合约品种；大合约要 300 万元以上才配得准。准确数字以 B0 阶段的最小可行资金报告为准。

### 3.5 验收标准

| 对象 | 标准 |
|---|---|
| B2 | 留出期夏普 ≥ 0.4；全样本最大回撤 ≤ 20%；通过参数测试、逐个去掉板块测试、成本翻倍测试（夏普下降不超过 0.2）；按计划投入的资金，通过最小可行资金报告 |
| B1 | 和方案 A 的标准相同。另外，事后实际波动和 8% 目标的偏差在 ±30% 以内 |
| 组合 | B1 和 B2 全样本的收益相关性 < 0.3；组合的夏普高于 B1、B2 各自的夏普，否则组合没有意义 |

### 3.6 实现路径

| 阶段 | 内容 | 完成标准 |
|---|---|---|
| B0 数据与合约 | 合约规格表、逐合约数据缓存、换月、复权连续价格；最小可行资金报告 | 单元测试：换月日期正确、复权正确、换月没用到未来数据 |
| B1 引擎 | 期货回测引擎：整数手、保证金、成本、涨跌停、换月 | 单元测试；用一个手算的小例子核对盈亏 |
| B2 CTA | v1 和三个对照组：开发期 → 检验 → 跑一次留出期 → 冻结为 `planB2-v1` | `docs/report_B2_v1.md` |
| B3 杠杆风险平价 | 复用方案 A 的权重模块，接上期货引擎；做纯期货版和混合版 | `docs/report_B1_v1.md` |
| B4 组合 | 60/40 组合；B1 有、无趋势过滤两个版本 | 组合报告 |
| B5 模拟盘 | 用期货公司的仿真账户跑 3–6 个月；每周出下单表，可以人工下单 | 模拟盘和模型的偏差都能解释 |
| B6 实盘 | 小资金起步，先做 B2 的中小合约品种，或 B1 的混合版 | 按第 6 节监控 |

每周调一次仓，人工下单完全来得及。如果改用程序化接口自动下单（比如 CTP、天勤 TqSdk），要按期货公司的要求做程序化交易报备。

## 6. 实盘运营与变更管理

### 6.1 例行操作

| 频率 | 方案 A | 方案 B |
|---|---|---|
| 每日 | — | 看保证金占用、涨跌停、换月日历 |
| 每周 | — | 生成信号和下单表，执行，记录成交 |
| 每月 | 生成调仓单，检查 QDII 溢价，执行，记录成交 | 出实盘和模型的偏差报告，统计成本 |
| 每季度 | 复核偏差、成本、数据 | 同左 |
| 每年 | 复核每个资产的角色是否还成立 | 复核品种池规则里的参数 |

### 6.2 失效与停止条件（实盘前写定）

具体阈值在回测完成后按固定规则定下（比如"回测最大回撤 × 1.5"），定了之后不再改。

| 情况 | 怎么办 |
|---|---|
| 回撤超过回测最大回撤的 1.5 倍 | 暂停追加资金，复核数据和执行；不临时改规则 |
| 方案 A 连续 24 个月跑输静态风险平价基准超过 3% | 复核趋势过滤还值不值得保留 |
| B2 滚动 36 个月的夏普 < 0 | 风险减半，复核 |
| 实际波动连续 3 个月超过目标的 1.5 倍 | 检查波动率估计和杠杆计算 |
| 实盘和模型的月度偏差超过 1% | 先查执行、数据、成本 |

### 6.3 变更管理

1. **版本号用 vX.Y。** X 变表示规则变了，Y 变表示修了 bug 或数据。实盘只运行打了版本标签的代码。
2. **改规则需要三个条件：**
   - 有书面的经济理由，"为了修掉某一次回撤"不算理由；
   - 只在开发期验证；
   - 不看留出期和实盘的结果来调参。
3. **每个策略每年最多改一次规则。**
4. 所有改动都写进 `research/trials.csv` 和 CHANGELOG。

## 附录：作者的问题与本方案的对应规则

| 文章里的问题 | 本方案的对应规则 |
|---|---|
| 16 个月里改了七八个版本，每次都修掉已知的回撤 | 版本冻结、每年最多改一次规则、登记每次试验、计算缩减夏普 |
| 换回测起点（2 月点名 2013、2015 年最差，4 月就改从 2016 年起算） | 开发期和留出期固定不变；做起点平移测试 |
| 资产池事后挑选（纳指、30 年国债、趋势强的品种） | 资产按角色事先选定；CTA 品种池按规则逐日生成 |
| 目标波动和实际波动对不上 | 统一定义；报告里列出事前和事后的波动 |
| 用指数代替期货加杠杆，没扣融资成本 | 代理数据一律用超额收益 |
| 用本币计价的新兴市场指数、回测不可交易的市场 | 只用可交易品种，统一按人民币计价 |
| 用价格水平算相关性 | 相关性一律用收益率算 |
| 同一个账户混跑信号冲突的策略 | B1、B2 分账运作，不合并信号 |
| 人工干预风控 | 实盘不干预，例外必须登记 |
| 用复杂的"独创"指标 | 先用最简单的公开方法，复杂方法要在开发期胜出才能用 |
