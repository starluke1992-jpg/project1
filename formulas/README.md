# 通达信 / 文华公式

| 文件 | 平台 | 内容 |
|---|---|---|
| `tdx_main.txt` | 通达信 | 主图：BOLL 三线 + 开多 / 开空 / 平仓 标注，表头显示当前持仓（1 多 / 0 空仓 / −1 空） |
| `tdx_sub.txt` | 通达信 | 4 个副图：KAMA_MID、BB_Width_Angle、ATR_Angle、DIFF_MK |
| `wenhua_model.txt` | 文华财经 | 交易模型：BOLL 三线 + BK / SK / SP / BP 信号，可直接用于模型交易 |
| `wenhua_sub.txt` | 文华财经 | 4 个辅助指标，同上 |

规则和参数默认值与 Python 版 `trend_signals` 相同：

- 开仓：趋势、动量、波动率三类因子共振，且只在空仓时开仓。
- 平仓：波动率收敛并反穿 KAMA，或者触发吊灯移动止损（最近 10 根最高/最低价 ∓ 2.5×ATR）。
- 参数都写在公式开头，`STOPK:=0` 可以关闭移动止损。

## 导入

**通达信**

1. 打开公式管理器（Ctrl+F），在“技术指标公式”下新建。
2. 主图公式：画线方法选“主图叠加”，把 `tdx_main.txt` 全部内容粘贴进去，测试公式，保存。
3. 副图：`tdx_sub.txt` 里按“===== 公式 N”分隔，每段新建一个指标，画线方法选“副图”。

**文华财经**（wh6 / wh8 / 赢顺云）

1. 新建“模型”，把 `wenhua_model.txt` 全部内容粘贴进去，编译，加载到主图。
2. 信号执行方式选“K线走完确认信号下单”。条件里用的是收盘价，盘中确认会让信号闪烁。
3. 辅助指标：`wenhua_sub.txt` 按“===== 指标 N”分隔，分别新建。

## 已经验证的和没有验证的

**已验证：公式逻辑。** `tests/test_formulas.py` 用一个小解释器（`tests/formula_interpreter.py`）直接运行这几个文件的公式文本，
在 IF 样本和 3 段 1500 根的随机行情上逐根比对：

- 持仓、开平仓信号与 Python 版完全一致。
- BOLL、KAMA、MID、两个角度、DIFF_MK 的数值误差在 0.01 以内。

解释器对“无效值”（指标预热期）按最严格的方式处理，所以预热期的保护条件也一起验证了。
另外，故意改错公式（换掉止损函数、调换信号顺序、改参数等）时，测试都会失败。

**没验证：能否在软件里直接编译通过。** 这里没有通达信和文华的环境，下面这些地方是按我对平台的了解写的，
如果编译报错或者信号对不上，先查这几处：

- 通达信
  - `BARSCOUNT(C)` 在第一根K线上返回 1。
  - `DMA` 的平滑系数要求小于 1，所以预热期用 0.99999。
  - `COLOR009BFE` 是橙色（通达信颜色按 BGR 顺序写）。
  - `DRAWICON` 图标 1、2 分别是上箭头、下箭头。
  - 输出名用了 `BBWA`、`ATRA`、`DIFFMK`，没用带下划线的名字。
- 文华
  - 用到了 `IFELSE`、`BARPOS`、`DMA`、`ATAN`。
  - `AUTOFILTER` 的行为按“一开一平、每根K线一个信号、按代码顺序生效”处理。持多时出现 SK 会被过滤，不占用这根K线。
  - `STICKLINE` 按文华的参数顺序写：`STICKLINE(条件,价1,价2,颜色,空心)`，和通达信不同。

**最直接的核对办法：** 把软件里的日线导出成 CSV（列：日期、开盘、最高、最低、收盘），然后运行
`python -m trend_signals --csv 导出的文件.csv`，把打印出来的信号日期和软件图上的标注对一下。

## 通达信的持仓是怎么算的

通达信公式没有循环，也不能引用自己上一根的值，没法直接写“空仓时才开仓、只平持有方向”的持仓逻辑。
`tdx_main.txt` 用的是状态转移合成：

1. 先把每根K线写成一个映射：收盘前分别处于 空仓 / 多头 / 空头 时，收盘后会变成什么状态（`GF0 / GL0 / GS0`）。
2. 再用 `REF(…,1)`、`REF(…,2)`、`REF(…,4)` … `REF(…,128)` 两两合成，得到最近 256 根K线连续作用的结果 `GF8`，即当前持仓。

256 根之前的状态按空仓处理。状态机在几十根K线内就会同步，测试里 1500 根的数据全部一致。

这也是移动止损用“最近 10 根最高价”而不用“开仓以来最高价”的原因：后者要知道开仓在哪根K线，
通达信只能近似计算，长历史上会和 Python、文华的结果对不上。
